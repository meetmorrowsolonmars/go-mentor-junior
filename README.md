# Food Delivery microservices course

This repository is a practical Go course built around a small food-delivery system. Two students can work independently: one implements the Order Service and the other implements the Restaurant Service.

## Start here

- [Project specification and API contract](docs/project.md)
- [Lesson 1: project layout](lessons/01-project-layout/README.md)
- [Architecture views](docs/architecture.md)
- [Development workflow](docs/development-workflow.md)
- [Specification changelog](docs/changelog.md)

The mentor maintains the root `README.md`, `docs/`, and `lessons/`. Students should not modify those paths in lesson submissions. Each student documents how to build, run, configure, and test their implementation in the README for their assigned service:

- [Order Service workspace](services/order/README.md)
- [Restaurant Service workspace](services/restaurant/README.md)

The detailed curriculum notes and future lesson outline are kept in the [mentor guide](docs/mentor-guide.md).
